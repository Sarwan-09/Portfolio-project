# Covid Dashboard Portfolio Project

Data exploration and visualization of global COVID-19 data from January 2020 to March 2021.

## Contents

- **SQLQuery1.sql** — SQL queries exploring COVID deaths and vaccinations (infection rates, death percentages, rolling vaccination counts, views, and temp tables).
- **Covid Dashboard from Jan2020 to March2021.twbx** — Tableau workbook for the dashboard.
- **Link-Covid Dashboard from Jan2020 to March2021** — Link to the published Tableau Public dashboard.
